# 鉄屑戦線 v0.7 新パーツ 画像仕様（28点）

既存20枚と同じルールで描いてください。

## 共通ルール
- **64×64 px・透過PNG**。全パーツを **組立済みの位置** に描き、ゲーム側は全PNGを **(0,0) に重ねるだけ**。
- 正面図。L/R は **画面上の左右**（見る側から見て）。
- アンチエイリアス・ディザなし。拡大は nearest。1px の黒系アウトライン（#0e0f14）。
- 配色：ガンメタル（#24272f〜#ccd4dc）／錆（#3c1f15〜#c68040）／オリーブ（#282d1b〜#889456）。発光部はアンバー（#7c3c0c / #f09e20 / #ffe28c）。parts.json の palette をそのまま使用。
- アンカー（parts.json と同じ）：
  - neck (32,22)
  - shoulderL (20,26) / shoulderR (44,26)
  - waist (32,44)
  - back (32,28)
  - mountL (20,21) / mountR (44,21)
  - rotorHub (32,4)
  - bodyCenter (32,34)
- 重ね順：**back → legs → body → arms → head → shoulder**。
- 腕は既存と同じく **左右セットで1枚**。
- 肩装備の取付側：
  - 肩スロット＝右肩、背スロットの肩装備＝左肩。
  - 逆側に付く場合、ゲームが左右反転し、さらに **1px右へずらし** ます。左右どちらか片側だけ描けばOKです。
- 2コマのパーツは `_1` `_2` で用意してください。12fpsで交互に切り替えます。
- 完成したら `manifest.js` の `PART_IMAGES` にファイル名（拡張子なし）を追加してください。追加された分から自動で画像に切り替わります。届いていない分はコード描画のままです。
- 参考：`/workspace/mech-assemble/screenshots/new_parts_fallback.png` は現在のコード描画版です。形と位置の目安にしてください。
